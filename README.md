# Northpeak Digital

A modern, responsive landing page for a fictional digital agency built as part of the **Digital Heroes Training Task**. The project focuses on clean design, performance, accessibility, and maintainable React architecture.

## Live Demo

**Website:** [Northpeak Digital | Modern Web Design & Development](https://northpeak-digital-three.vercel.app/)

## Features

* Responsive landing page optimized for desktop, tablet, and mobile
* Modern hero section with image carousel
* Service cards with hover animations
* Testimonials section
* Pricing section
* Contact form with client-side validation
* Smooth page animations using Motion
* Mobile-friendly navigation
* SEO-friendly metadata
* Optimized image assets for improved loading performance

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Motion
* React Hook Form
* Zod

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build

```
